# Legal & Regulatory Framework Matrix

| Statute / Regulation | Jurisdiction | Description & Application | Potential Violation Point |
| :--- | :--- | :--- | :--- |
| **Computer Fraud & Abuse Act (CFAA)** <br>`18 U.S.C. § 1030(a)(5)` | Federal | Intentional access to a protected computer without authorization or exceeding authorized access. | Deleting server logs to cover up unauthorized configuration changes. |
| **Clean Water Act (CWA)** <br>`33 U.S.C. § 1319(c)` | Federal (EPA) | Criminal liability for false statements, representations, or tampering with monitoring devices. | Altering sensor telemetry data sent to regulatory compliance portals. |
| **Texas Penal Code § 33.02** | State (Texas) | Computer Security Breach — intentionally accessing a computer network without consent. | Utilizing another user's credentials to alter system logs. |
